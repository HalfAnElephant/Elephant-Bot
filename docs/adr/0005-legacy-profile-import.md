# ADR 0005：旧人格与用户档案的受限迁移

从 Koishi SOUL 提取身份/性格/表达风格，删去发言决策、长度限制与旧工具契约。USER 中长期偏好和关系仅迁入已存在的管理员私聊，不并入公共人格；表达学习库和无法确认删除状态的历史 Mem0 快照不导入。

采用离线、显式管理脚本写入现有记忆结构，无新依赖和表结构。脚本以已接收的私聊事件绑定目标、检查当前配置授权，在单个事务内导入经整理的条目。文档来源只作为 provenance，使用独立 legacy-profile 来源 ID 与 inference 类型；不伪造消息或放宽线上记忆证据检查。每条独立来源标识使遗忘、备份恢复和重导入沿用既有删除墓碑。

私人摘要和必要来源摘录只保存在受限数据库中，临时清单导入后删除。普通纠正/遗忘入口继续有效；未来真正迁移 Mem0 时必须先取得带有效性、作用域和删除状态的当前导出，不能拿历史备份替代。
