# ADR 0002 社交策略与作用域记忆

状态为接受。实现以执行文档第 7—10 节为边界，采用本项目独立实现，没有复制上游控制器或权重。

Core 是唯一数据库写入者。SpeechPolicy、三个 Judge 和会话窗口返回数据或动作，不获得任务执行权限。命令鉴权和确定性命令路由先于普通聊天。shadow 对外动作恒为 IGNORE，只保留候选动作，不授予 TaskRouter 权限。

未通过本地中文数据校准前，social 默认关闭。受邀元信息由平台解析，字符串昵称不构成 mention。普通自然参与需要全量可见上下文以及预算、冷却和语义信号共同通过。Jev 或结构化模型失败时 ABSTAIN，受邀请求仍走规则路径。HTTP 调用总期限 1.5 秒，无隐式重试，连续三次失败打开 30 秒熔断。

长期记忆先用 SQL 限定访问作用域，再进行中文字符 n-gram 与精确词条查询。没有向量 key 时只使用关键词。可选向量写入前再次校验证据，检索只使用模型、版本和维度一致的向量。索引更新事件和事实在同一事务提交。当前规模在有权访问的候选集内扫描，无外部索引或缓存。

来源撤回记录持久化为 tombstone，依赖记录同步失效并清空向量，阻止旧摘要重新引入来源。记忆删除也撤销该来源的其他依赖记录。这是保守选择，同一条消息的其他事实可能一起失效。共享撤销 epoch 使任意记忆变更后的所有已装配回复重新检查，覆盖人工全局记忆的跨会话撤销。

人格核心配置与群覆盖独立。覆盖通过同目录临时文件、fsync 和原子 replace 保存，成功后切换内存。回合持有序列化不可变快照及其摘要版本。配置解析或写入失败保留旧状态。部署文件系统需要提供原子 replace 语义，单一 Core 写入者负责串行更新。

默认关闭自动事实提取与向量维护，提供 Core 内低优先级增量维护接口。当前不启用自动黑话表达、每日全群整理或跨会话个人画像。候选建议需要 Core 的显式授权才能提交。task_verified 需要专门任务验收证据通道，当前服务拒绝以聊天事件冒充任务验收。
